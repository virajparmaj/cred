# Implementation decisions

- **Direct point sizing:** the supplied redesign replaces the scaled canvas with a 256 × 320 pt overview and 256 × 392 pt base detail view. Each multi-context or multi-pool selector and visible action-feedback message gets its own 32 pt extension. A separately identified demo entry adds 24 pt to the overview. Quota values and hit targets are never squeezed to accommodate optional controls.

- **Independent repository:** all source, environments, build output, tests, and docs belong in the new `cred` repository. CredClaude and CredCodex remain unchanged.
- **Python/macOS:** Python 3.11+ provides a testable shared core; AppKit/PyObjC supply the status item, transient usage popover, and independent Settings window. rumps remains a notification helper. Cocoa is imported only by native paths so the core can be tested without a Mac UI.
- **Popover hierarchy:** four coding-product rows use official locally bundled artwork, percent used, actual window labels, and reset countdowns. Provider-specific detail pages stay inside a bounded, non-scrolling popover; Antigravity/Codex/Claude use two unboxed quota columns, while Cursor exposes dashboard-only readiness. Context/pool selectors preserve identities across refreshes. Quick Refresh and dashboard links are available in details; sign-in, configuration and maintenance remain in Settings. Reported five-hour windows take priority; account/context/pool values never aggregate. Menu-bar text pins remain in storage for compatibility but the status item is icon-only. Unsupported lifetime and token figures are omitted rather than estimated.
- **Popover composition:** use 16 pt margins, 40 pt headers/footers, four 56 pt provider rows, 44 pt row icons and 56 pt detail icons, and 4 pt neutral progress tracks only for known usage. System type uses 13 pt titles/actions, 11 pt secondary labels, 12 pt metadata values, 15 pt detail titles, and 26 pt usage values with an 11 pt suffix; unusually wide metrics may shrink to 18 pt. Two 100 pt quota columns and plain metadata replace stacked card backgrounds. All custom window widths are 20% narrower, including the Settings window. Selected-row outlines are removed while click navigation, hover feedback and a small neutral keyboard cue remain. Settings/Quit are icon-only with accessible names and tooltips. Native material, selectors, provider artwork, and system framing remain; action backgrounds and hover highlights have 6 pt corners. The overview update age uses the oldest successful update among visible numerical readings. Source and verification remain visible when action feedback is shown.
- **Conservative identity:** an individual subject must be verified before account-bound cache reuse or quota notifications. Tenant/account IDs, email, plan, and session IDs are not individual proof.
- **Truthful source gates:** a dashboard-only integration remains visible. Antigravity uses the structured schema supplied by real CLI 1.4.0 output; unsupported shapes are rejected. A consumer product never borrows a coding tool's quota.
- **Passive operation:** no inference, keepalive, automatic account switching, credential copying/renewal, purchases, history database, or cloud backend.
- **Explicit experimental use:** per-connection opt-in is necessary for an undocumented source and insufficient to establish safe units, passive behavior, or identity.
- **Private normalized state:** atomic schema-versioned JSON retains exact decimals and original timestamps. No old credentials or unattributed snapshots are imported.
- **Native notification limits:** threshold defaults are 80 and 95 percent with five-point hysteresis. Demo, fixture, stale, expired, undated, and identity-unverified observations never notify.
- **Packaging:** arm64 PyInstaller onedir bundles the interpreter, dependencies, ingestion command, and assets. Installation is app-specific; startup and launch require explicit options. Ad-hoc signing supports local tests; Developer ID signing and notarization are distinct release gates.
- **Licensing:** preserve Claude's complete MIT attribution. CredCodex's inspected checkout lacks license metadata; resolve permission and choose this project's license before external redistribution.
