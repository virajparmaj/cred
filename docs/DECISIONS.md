# Implementation decisions

- **Proportional enlargement:** the compact 200 × 260 layout renders at 125% in a 250 × 325 pt window. Native coordinate scaling enlarges all content consistently without rewriting individual dimensions or changing provider behavior.

- **Independent repository:** all source, environments, build output, tests, and docs belong in the new `cred` repository. CredClaude and CredCodex remain unchanged.
- **Python/macOS:** Python 3.11+ provides a testable shared core; AppKit/PyObjC supply the status item, transient usage popover, and independent Settings window. rumps remains a notification helper. Cocoa is imported only by native paths so the core can be tested without a Mac UI.
- **Popover hierarchy:** four coding-product rows use official locally bundled artwork, percent used, actual window labels, and reset countdowns. Provider-specific detail pages stay inside a bounded, non-scrolling popover; Codex/Claude use two quota cards, while Cursor/Antigravity expose truthful source readiness. Context/pool selectors preserve identities across refreshes. Quick Refresh and dashboard links are available in details; sign-in, configuration and maintenance remain in Settings. Reported five-hour windows take priority; account/context/pool values never aggregate. Menu-bar text pins remain in storage for compatibility but the status item is icon-only. Unsupported lifetime and token figures are omitted rather than estimated.
- **Fixed composition:** overview and all details use a 200 × 260 pt canvas, including in demo mode. The four 43 pt provider rows stay intact; the separate synthetic demo entry uses the spare area above the footer. Following the styling revision, the original native material and controls are restored: automatic light/dark appearance, borderless action buttons, standard pickers and hover-only row highlights. The latest layout halves the previous 400 × 520 pt footprint. Quotas and metadata are tiled to use the smaller canvas; progress and focus highlights use neutral colors. Official vendor artwork is unchanged. Native AppKit owns arrow placement and window framing.
- **Conservative identity:** an individual subject must be verified before account-bound cache reuse or quota notifications. Tenant/account IDs, email, plan, and session IDs are not individual proof.
- **Truthful source gates:** a dashboard-only integration remains visible. An unknown Antigravity schema is not guessed and a consumer product never borrows a coding tool's quota.
- **Passive operation:** no inference, keepalive, automatic account switching, credential copying/renewal, purchases, history database, or cloud backend.
- **Explicit experimental use:** per-connection opt-in is necessary for an undocumented source and insufficient to establish safe units, passive behavior, or identity.
- **Private normalized state:** atomic schema-versioned JSON retains exact decimals and original timestamps. No old credentials or unattributed snapshots are imported.
- **Native notification limits:** threshold defaults are 80 and 95 percent with five-point hysteresis. Demo, fixture, stale, expired, undated, and identity-unverified observations never notify.
- **Packaging:** arm64 PyInstaller onedir bundles the interpreter, dependencies, ingestion command, and assets. Installation is app-specific; startup and launch require explicit options. Ad-hoc signing supports local tests; Developer ID signing and notarization are distinct release gates.
- **Licensing:** preserve Claude's complete MIT attribution. CredCodex's inspected checkout lacks license metadata; resolve permission and choose this project's license before external redistribution.
